# Nota Backend

Backend изолирован в этой директории. Команды выполняются из `Backend/`.

```bash
uv sync
uv run alembic upgrade head
uv run uvicorn main:app --reload
uv run pytest
```

API: `http://localhost:8000`, Swagger: `http://localhost:8000/docs`.

## Документы и участники

Перед запуском обновлённой версии выполните `uv run alembic upgrade head`:
миграция `0002_document_members` добавляет участников документов, сохраняя существующие данные.
В Docker Compose миграции выполняются сервисом `migrations`.

`GET /documents/` возвращает собственные и доступные пользователю документы;
`POST /documents/` создаёт документ. Существующие главы также отображаются в списке документов.
`GET /documents/{id}/members` показывает участников, а `POST /documents/{id}/members`
с телом `{"username": "имя"}` предоставляет зарегистрированному пользователю доступ на чтение
и редактирование. Добавлять участников может только владелец. Доступ к другим документам
и книгам не предоставляется. Изменения видны после повторного открытия документа;
одновременное редактирование в реальном времени не реализовано.
